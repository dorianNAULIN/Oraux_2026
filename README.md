# 🚀 Intégration GitHub - Overleaf

Ce dépôt est configuré pour être synchronisé avec Overleaf.

---

## 🛠️ Configuration Initiale (À faire une seule fois)

Pour l'ajouter à vos projets et l'importer dans Overleaf, suivez ces étapes depuis la page principale de ce dépôt GitHub :

### 1. Mettre le projet de côté sur GitHub
1. En haut à droite de cette page, cliquez sur le bouton **⭐ Star** pour retrouver facilement le dépôt.

### 2. Importer le projet dans Overleaf
1. Connectez-vous à votre compte [Overleaf](https://www.overleaf.com).
2. Sur votre tableau de bord (Dashboard), cliquez sur le bouton vert **New Project**.
3. Dans le menu déroulant, sélectionnez **Import from GitHub**.
4. Une liste de vos dépôts apparaît :
   * *Si le dépôt n'apparaît pas :* Assurez-vous d'avoir lié votre compte GitHub à Overleaf dans vos paramètres de compte (*Account Settings -> Integrations*).
5. Cliquez sur **Import** en face du nom de ce dépôt (`Oraux 2026`).

## 🔄 Routine de Travail (Au quotidien)

[ Étape 1 : PULL ] ➡️ [ Étape 2 : ÉCRIRE ] ➡️ [ Étape 3 : PUSH ]
(Overleaf)            (Overleaf)            (Overleaf)

### 🔁 Étape 1 : Synchroniser avant de commencer (PULL)
Avant d'écrire la moindre ligne sur Overleaf
1. Ouvrez le projet sur Overleaf.
2. Cliquez sur le bouton **Menu** (en haut à gauche).
3. Cliquez sur **GitHub**.
4. Cliquez sur **Pull GitHub changes into Overleaf** (Importer les modifications de GitHub vers Overleaf).

### ✍️ Étape 2 : Rédiger votre contenu
* Rédigez votre texte...


### 🚀 Étape 3 : Sauvegarder votre travail sur GitHub (PUSH)
Une fois votre session de travail terminée (ou à la fin de la journée) :
1. Cliquez sur le bouton **Menu** (en haut à gauche).
2. Cliquez sur **GitHub**.
3. Cliquez sur **Push Overleaf changes to GitHub** (Exporter les modifications d'Overleaf vers GitHub).
4. Ajoutez un **message de commit** clair (ex: `Exercice moi`).
